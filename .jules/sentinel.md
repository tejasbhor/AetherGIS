## 2025-06-09 - HTML Escape Shadowing and XSS in Manual Generation
**Vulnerability:** XSS vulnerability in report_service.py where user-controlled variables (e.g. layer_id, job_id, pipeline parameters) were injected unescaped into manually generated HTML strings. Also, the local variable holding the generated template was named `html`.
**Learning:** Manual HTML string generation is inherently risky without an auto-escaping template engine. A subtle trap in Python is naming a variable `html`, which shadows the standard library `html` module, preventing the use of `html.escape()`. Furthermore, slicing strings *after* escaping can lead to malformed HTML entities, so truncation should always occur before escaping.
**Prevention:** Always use `html.escape()` for user-controlled variables when manually constructing HTML. Avoid using standard library module names (like `html`) as local variables. Ensure string manipulations like slicing are completed prior to applying HTML escaping.
